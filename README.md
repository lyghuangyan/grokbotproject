# Grok Bot Collaboration Project

此仓库用于多个 Grok Bot 协作（项目经理、产品经理、UI/UX设计、全栈开发、测试）。

## 目录结构
- `prd/` — 产品需求文档（PRD、用户故事、验收标准）
- `design/` — UI/UX 设计方案与视觉规范
- `code/` — 开发代码与接口文档。待办应用在 `code/todo-app/`（见该目录 README）。`code/index.html` 是早期单文件原型，仍然保留。
- `test/` — 测试用例与测试报告
- `acceptance/` — 项目经理最终验收结论

所有 Bot 共享此仓库进行成果交换与协作。
