# Todo List 设计规范

> 文件：`design/20261101-todo-list-design.md`
> 版本：v1.0 · 2026-11-01
> 组件体系：shadcn/ui（Radix + Tailwind CSS），图标用 lucide-react
> 风格：现代、简洁、专业，不加渐变、玻璃拟态或大面积装饰色

---

## 1. 设计原则

1. **内容优先**：页面上的视觉重点只有输入区和列表，其他元素都弱化处理。
2. **层级清楚**：标题、输入区、列表、说明四层，用字号、字重和灰阶区分，不靠颜色区分。
3. **克制用色**：只有主按钮、聚焦环和勾选框用主色，删除操作用危险色，其余全是中性灰。
4. **反馈及时**：悬停、聚焦、勾选、删除都有明确但轻量的状态变化。

---

## 2. 布局

### 2.1 页面结构

```
┌────────────────────────────────────────┐
│               (页面背景 muted)             │
│   ┌────────────────────────────────┐   │
│   │  待办清单                 3 项未完成 │  ← Header
│   │  ─────────────────────────────── │
│   │  [ 添加一项待办…          ] [添加] │  ← 输入区
│   │  ─────────────────────────────── │
│   │  ☐ 新加的待办               🗑     │  ← 列表
│   │  ☑ ~~已完成的待办~~          🗑     │
│   │  ☐ 较早的待办               🗑     │
│   └────────────────────────────────┘   │
│        数据仅保存在当前浏览器本地            │  ← 底部说明
└────────────────────────────────────────┘
```

### 2.2 尺寸与响应式

| 项目 | 桌面端（≥640px） | 移动端（<640px） |
|---|---|---|
| 容器最大宽度 | `max-w-xl`（576px），水平居中 | 100%，左右留 16px |
| 页面上边距 | 80px（`pt-20`） | 24px（`pt-6`） |
| 卡片内边距 | 24px（`p-6`） | 16px（`p-4`） |
| 输入区 | 输入框和按钮在同一行 | 仍然同一行，按钮只显示图标 `+` 加上 `aria-label` |
| 列表项高度 | 最小 44px | 最小 48px（便于手指点击） |
| 删除按钮 | 悬停整行时才显示 | 一直显示（触屏没有悬停） |

### 2.3 区块说明

- **Header**：左边是标题“待办清单”，右边是计数“N 项未完成”（全部完成时显示“全部完成”）。
- **输入区**：`Input` 加主按钮 `Button`。按回车或点按钮都能添加；内容为空时按钮置灰。
- **列表**：用 `Separator` 分隔每一项，或者每项之间用 1px 边框。新加的待办插到最上面；勾选完成的待办留在原位，不移动。
- **空状态**：没有待办时，在列表区域居中显示（见 4.5）。
- **底部说明**：放在卡片外面、居中，用 `text-xs text-muted-foreground`。

## 3. 视觉规范

### 3.1 色板（基于 shadcn 的 Zinc 主题，HSL 写成 CSS 变量）

| Token | 亮色模式 | 用途 |
|---|---|---|
| `--background` | `0 0% 100%`（#FFFFFF） | 卡片背景 |
| `--muted` | `240 4.8% 95.9%`（#F4F4F5） | 页面背景、悬停背景 |
| `--foreground` | `240 10% 3.9%`（#09090B） | 主要文字 |
| `--muted-foreground` | `240 3.8% 46.1%`（#71717A） | 次要文字、已完成文字、占位符 |
| `--border` | `240 5.9% 90%`（#E4E4E7） | 边框、分隔线 |
| `--primary` | `240 5.9% 10%`（#18181B） | 主按钮、勾选框选中态 |
| `--primary-foreground` | `0 0% 98%`（#FAFAFA） | 主按钮上的文字 |
| `--ring` | `240 5.9% 10%` | 聚焦环 |
| `--destructive` | `0 72% 51%`（#DC2626） | 删除图标悬停色 |

> 如果需要品牌色，只替换 `--primary` 和 `--ring` 两个变量，例如 Blue 600（#2563EB）。其他变量保持中性灰。
> 暗色模式直接用 shadcn Zinc 默认的 `.dark` 变量，不需要额外设计。

### 3.2 字体

- 字体栈：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`

| 层级 | 样式 | Tailwind |
|---|---|---|
| 页面标题 | 24px / 600 / 行高 32px | `text-2xl font-semibold tracking-tight` |
| 计数 | 14px / 400 | `text-sm text-muted-foreground` |
| 待办文本 | 14px / 400 / 行高 20px | `text-sm` |
| 空状态标题 | 14px / 500 | `text-sm font-medium` |
| 空状态描述、底部说明 | 12px / 400 | `text-xs text-muted-foreground` |

### 3.3 间距（以 4px 为基准）

| 场景 | 值 |
|---|---|
| Header 和输入区之间 | 16px（`mb-4`） |
| 输入框和按钮之间 | 8px（`gap-2`） |
| 输入区和列表之间 | 16px |
| 列表项内边距 | 上下 10px，左右 12px（`py-2.5 px-3`） |
| 勾选框和文本之间 | 12px（`gap-3`） |
| 卡片和底部说明之间 | 16px |

### 3.4 圆角、阴影、动效

- 圆角：卡片 `rounded-xl`（12px），输入框、按钮、列表项悬停背景用 `rounded-md`（6px），勾选框 `rounded-sm`（4px）。
- 阴影：卡片只用 `shadow-sm` 加 1px `border`，别的地方都不加阴影。
- 动效：统一 150ms `ease-out`。新加一项时淡入并从上方下移 4px；删除时淡出。如果系统开了 `prefers-reduced-motion`，就关闭这些位移动画。

## 4. 组件与状态

### 4.1 组件选型

| 区块 | shadcn/ui 组件 | Ant Design 对应组件（备选） |
|---|---|---|
| 容器 | `Card` / `CardHeader` / `CardContent` | `Card` |
| 输入框 | `Input` | `Input` |
| 添加按钮 | `Button`（default） | `Button type="primary"` |
| 勾选 | `Checkbox` | `Checkbox` |
| 删除 | `Button variant="ghost" size="icon"` 加 `Trash2` 图标 | `Button type="text" icon={<DeleteOutlined/>}` |
| 分隔 | `Separator` | `Divider` |
| 删除提示（可选） | `Sonner` toast，带“撤销”按钮 | `message` |

### 4.2 输入框 `Input`

| 状态 | 表现 |
|---|---|
| 默认 | 高 40px（`h-10`），1px `border`，占位符“添加一项待办…” |
| 悬停 | 边框颜色稍微加深到 `zinc-300` |
| 聚焦 | 2px `ring` 加 2px 偏移，边框不变 |
| 已输入 | 文字用 `foreground` 色；按回车提交，提交后清空输入框，焦点留在输入框里 |
| 只有空格 | 不允许提交，按钮保持置灰 |
| 字数上限 | 200 字，超出就截断，不另外报错 |

### 4.3 添加按钮 `Button`

| 状态 | 表现 |
|---|---|
| 默认 | `primary` 背景，文字“添加”，加 `Plus` 图标，高 40px |
| 悬停 | 背景变为 `primary/90` |
| 按下 | 背景变为 `primary/80` |
| 聚焦（键盘） | 显示 `ring` 聚焦环 |
| 禁用（输入为空） | 透明度 50%，鼠标为 `not-allowed` |

### 4.4 待办项

```
[☐]  待办文本内容可以换行……                    [🗑]
```

| 状态 | 表现 |
|---|---|
| 默认 | 透明背景，文字用 `foreground` 色 |
| 悬停 | 背景变为 `muted/60`，删除按钮淡入显示 |
| 键盘聚焦（focus-within） | 和悬停一样，并且当前聚焦的控件显示 `ring` |
| 已完成 | 勾选框为选中态（`primary` 填充加白色对勾）；文字变为 `muted-foreground`，加 `line-through`；位置不变 |
| 删除按钮悬停 | 图标变为 `destructive` 色，背景变为 `destructive/10` |
| 长文本 | 自动换行（`break-words`），勾选框和删除按钮跟第一行对齐 |

交互说明：
- 点勾选框或者点文本，都能切换完成状态（整个 label 是可点击区域）。
- 删除立即生效。可选：弹一个 toast“已删除”，5 秒内可以撤销。
- 勾选框和删除按钮的可点击区域都不小于 32×32px，移动端不小于 44×44px。

### 4.5 空状态

```
            [ ClipboardList 图标，32px，muted-foreground ]
                       还没有待办
                在上方输入框添加第一项吧
```

- 上下内边距 40px，内容居中。
- 图标外面套一个 48px 的圆形 `muted` 背景，图标本身 24px。
- 只放提示文字，不放按钮；需要操作时由输入框承担，避免重复入口。

### 4.6 底部说明

- 文案：“数据仅保存在当前浏览器本地，清除浏览器数据后会丢失。”
- 可以在文字前加一个 `Info` 小图标（12px）。

---

## 5. 无障碍

- 输入框加 `aria-label="新待办"`；删除按钮加 `aria-label="删除：{待办文本}"`。
- 列表用 `<ul>` / `<li>`；计数区域加 `aria-live="polite"`，数量变化时读屏软件会播报。
- 文字对比度：正文 ≥ 4.5:1；`muted-foreground` 在白色背景上约 4.8:1，符合 WCAG AA。
- 键盘操作：Tab 顺序是输入框、添加按钮，然后每项的勾选框和删除按钮；勾选框按空格切换。
