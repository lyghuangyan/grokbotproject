# Todo List 设计规范

> 文件：`design/20261101-todo-list-design.md` · v1.6（最终版）· 2026-11-01 · 里程碑 M2 · 依据 PRD v1.3（`/workspace/prd/20261101-todo-list-prd.md`）
> 组件体系：shadcn/ui（Radix + Tailwind CSS），图标 lucide-react；Ant Design 对应组件见 4.1
> 风格：现代、简洁、专业；不用渐变、玻璃拟态、大面积装饰色
> 交互规则（PRD 第 5 节）：空输入或纯空格时添加按钮禁用、Enter 无效；最多 200 字符，不显示字数计数；新待办置顶；已完成项保持原位；删除不确认；添加后清空输入框并保持焦点；页面底部一行本地存储说明
> 本期不做（不留可见入口）：编辑、分类标签、截止日期、拖拽排序、筛选切换

---

## 1. 设计原则

1. 内容优先：视觉重点只有输入区和列表。
2. 层级清楚：标题、输入区、列表、底部统计四层，用字号、字重、灰阶区分。
3. 克制用色：主色只用于主按钮、聚焦环、勾选框；删除悬停用危险色；其余为中性灰。
4. 反馈及时：悬停、聚焦、勾选、删除都有轻量状态变化。

## 2. 布局（D1）

### 2.1 页面结构

```
┌──────────────────────────────────────────┐
│               页面背景 muted               │
│   ┌──────────────────────────────────┐   │
│   │  待办清单                          │  ← Header
│   │  [ 添加一项待办…          ] [添加] │  ← 输入区
│   │  ─────────────────────────────── │
│   │  ☐ 新加的待办               🗑     │  ← 列表区
│   │  ☑ ~~已完成的待办~~          🗑     │
│   │  ☐ 较早的待办               🗑     │
│   │  ─────────────────────────────── │
│   │  剩余 2 项 · 共 3 项               │  ← 底部统计
│   └──────────────────────────────────┘   │
│   数据仅保存在本浏览器中，清除浏览器数据后将丢失。   │  ← 存储说明
└──────────────────────────────────────────┘
```

### 2.2 区块说明

- Header：标题“待办清单”，`text-2xl font-semibold`。
- 输入区：`Input` + 主按钮 `Button`；回车或点击添加；trim 后为空时按钮禁用，Enter 无效果；提交时去除首尾空格。
- 列表区：`<ul>`，每项之间 1px `border` 分隔；新待办插到顶部；勾选后原位不动。
- 底部统计：卡片内底部，`CardFooter`，以 PRD v1.3 为准。桌面端显示“剩余 N 项 · 共 M 项”（N = 未完成数，M = 总数，两项都必须显示）；≤480px 只显示“剩余 N 项”；全部完成时两端都只显示“全部完成”，不带“共 M 项”；列表为空时隐藏统计（容器保留在 DOM 中）。
- 存储说明：卡片外居中一行小字，文案固定为「数据仅保存在本浏览器中，清除浏览器数据后将丢失。」，`text-xs text-muted-foreground`。
- 存储异常提示（P2）：加载时存储不可用、会话中写入失败或备份失败时，在输入区下方显示一条不打扰的提示条（见 4.7），不弹窗。

## 3. 视觉规范（D3）

### 3.1 色板（shadcn Zinc 主题，CSS 变量 HSL）

| Token | 亮色值 | 用途 |
|---|---|---|
| `--background` | `0 0% 100%`（#FFFFFF） | 卡片背景 |
| `--muted` | `240 4.8% 95.9%`（#F4F4F5） | 页面背景、悬停背景 |
| `--foreground` | `240 10% 3.9%`（#09090B） | 主文字 |
| `--muted-foreground` | `240 3.8% 46.1%`（#71717A） | 次要文字、已完成文字、占位符、统计 |
| `--border` | `240 5.9% 90%`（#E4E4E7） | 边框、分隔线 |
| `--primary` | `240 5.9% 10%`（#18181B） | 主按钮、勾选框选中 |
| `--primary-foreground` | `0 0% 98%`（#FAFAFA） | 主按钮文字 |
| `--ring` | `240 5.9% 10%` | 聚焦环 |
| `--destructive` | `0 72% 51%`（#DC2626） | 删除按钮悬停 |

品牌色需求时只替换 `--primary` 和 `--ring`（如 Blue 600 #2563EB）。暗色模式沿用 shadcn Zinc 默认 `.dark` 变量。

### 3.2 字体与字号

字体栈：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`

| 层级 | 桌面端（≥1024px） | 平板（481–1023px） | 移动端（≤480px） | Tailwind |
|---|---|---|---|---|
| 页面标题 | 24px / 600 / 32px | 481–639px 为 20px / 600 / 28px；≥640px 为 24px / 600 / 32px | 20px / 600 / 28px | `text-xl sm:text-2xl font-semibold tracking-tight` |
| 待办文本 | 14px / 400 / 20px | 16px / 400 / 24px | 16px / 400 / 24px | `text-base lg:text-sm` |
| 输入框文字 | 14px | 16px | 16px（避免 iOS 聚焦缩放） | `text-base lg:text-sm` |
| 底部统计 | 13px / 400 | 13px / 400 | 13px / 400 | `text-[13px] text-muted-foreground` |
| 空状态标题 | 14px / 500 | 14px / 500 | 14px / 500 | `text-sm font-medium` |
| 空状态描述、存储说明 | 12px / 400 | 12px / 400 | 12px / 400 | `text-xs text-muted-foreground` |

平板区间的字号就是上表 Tailwind 类在 481–1023px 的实际效果，开发和测试以此为准。

### 3.3 间距（4px 基准）

| 场景 | 值 |
|---|---|
| Header 与输入区 | 16px |
| 输入框与按钮 | 8px（`gap-2`） |
| 输入区与列表 | 16px |
| 列表项内边距 | 桌面 `py-2.5 px-3`；移动 `py-3 px-2` |
| 勾选框与文本 | 12px（`gap-3`） |
| 列表与底部统计 | 12px，上方 1px 分隔线 |
| 卡片与存储说明 | 16px |

### 3.4 圆角、阴影、动效

- 圆角：卡片 12px（`rounded-xl`）；输入框、按钮、列表项悬停背景 6px（`rounded-md`）；勾选框 4px（`rounded-sm`）。
- 阴影：卡片 `shadow-sm` + 1px `border`，其他不加阴影。
- 动效：150ms `ease-out`。新增项淡入并下移 4px；删除项淡出；`prefers-reduced-motion` 时关闭位移。

## 4. 组件与状态（D2）

### 4.1 组件选型

| 区块 | shadcn/ui | Ant Design 备选 |
|---|---|---|
| 容器 | `Card` / `CardHeader` / `CardContent` / `CardFooter` | `Card` |
| 输入框 | `Input` | `Input` |
| 添加按钮 | `Button`（default） | `Button type="primary"` |
| 勾选 | `Checkbox` | `Checkbox` |
| 删除 | `Button variant="ghost" size="icon"` + `Trash2` | `Button type="text" icon={<DeleteOutlined/>}` |
| 分隔 | `Separator` | `Divider` |

### 4.2 输入框

| 状态 | 表现 |
|---|---|
| 默认 | 高 40px（移动 44px），1px `border`，占位符“添加一项待办…” |
| 悬停 | 边框加深为 `zinc-300` |
| 聚焦 | 2px `ring` + 2px offset |
| 提交后 | 清空，焦点保留在输入框 |
| 纯空格 | 视同空输入，不可提交，不清空输入框 |
| 上限 | 200 字符（`maxLength={200}`，粘贴超长内容截断）；不显示字数计数 |

### 4.3 添加按钮

| 状态 | 表现 |
|---|---|
| 默认 | `primary` 背景，`Plus` 图标 + “添加”，高同输入框 |
| 悬停 | `primary/90` |
| 按下 | `primary/80` |
| 键盘聚焦 | `ring` |
| 禁用 | 透明度 50%，`cursor-not-allowed` |

### 4.4 待办项

| 状态 | 表现 |
|---|---|
| 未完成 | 透明背景，`foreground` 文字，勾选框空心 1px `primary` 边框 |
| 已完成 | 勾选框 `primary` 填充 + 白色对勾；文字 `muted-foreground` + `line-through`；位置不变 |
| 悬停（≥1024px 鼠标设备） | 背景 `muted/60`，删除按钮淡入 |
| 键盘聚焦 | 同悬停（`focus-within`），聚焦控件显示 `ring` |
| 长文本 | `break-words` 换行，勾选框与删除按钮对齐首行 |

交互：点击勾选框或文本切换完成状态（整个 label 可点击）；可点击区域桌面 ≥ 32×32px，移动 ≥ 44×44px。

### 4.5 删除按钮

| 状态 | 表现 |
|---|---|
| 默认（≥1024px 且鼠标设备，`(hover: hover)`） | 隐藏（`opacity-0`，仍在 DOM 中可 Tab 聚焦），行悬停或 `focus-within` 时显示 |
| 默认（<1024px，或 ≥1024px 的触屏设备 `(hover: none)`） | 常显，`muted-foreground` 色 |
| 悬停 | 图标 `destructive`，背景 `destructive/10` |
| 点击 | 立即删除，不弹确认（PRD 规定） |
| 无障碍 | `aria-label="删除待办"`（PRD 指定）；可 Tab 聚焦，Enter/空格触发 |
| 删除后焦点 | 移到下一条的删除按钮；没有下一条就移到上一条的删除按钮；列表删空后回到输入框；焦点不能落到 `body`。用鼠标或键盘删除都按这套规则；宽屏鼠标设备上，下一条的删除按钮会因为拿到焦点而显示（`focus-within`），这是预期行为 |

实现参考：`opacity-100 lg:opacity-0 lg:group-hover:opacity-100 lg:group-focus-within:opacity-100`，再用 `@media (hover: none)` 覆盖为 `opacity-100`。

### 4.6 空状态

```
        [ ClipboardList 图标 24px，48px 圆形 muted 底 ]
              还没有待办，添加一条吧
```

上下内边距 40px，居中；文案按 PRD「还没有待办，添加一条吧」，`text-sm text-muted-foreground`；不放按钮（输入框即入口）；空状态时隐藏底部统计；删除最后一条后立即切到空状态。

### 4.7 存储异常提示（P2）

| 项目 | 规范 |
|---|---|
| 触发 | 三种情况任一发生即显示：① 加载时存储不可用；② 会话中写入失败；③ 备份失败。数据损坏且修复成功时不提示 |
| 位置 | 输入区下方、列表上方，宽度与卡片内容一致 |
| 样式 | shadcn `Alert`：背景 `amber-50`，边框 `amber-200`，文字 `amber-900`，`AlertTriangle` 图标 16px，`text-xs`，圆角 6px，内边距 `py-2 px-3` |
| 文案 | 「当前无法保存到本地，本次的修改不会被保存，关闭或刷新页面后将丢失。」（PRD v1.3 原文） |
| 行为 | 常驻本次会话，不自动消失，不阻断操作；`role="status"` |
| 触发后状态 | 进入仅内存模式：本次会话停止写入，修改只留在内存，关闭或刷新后丢失；提示条全程常驻；下次打开页面重新尝试。存储可读不可写时照常显示已有数据 |

| 项目 | 桌面端（≥1024px） | 移动端（≤480px） |

## 6. 无障碍

- 输入框 `aria-label="新待办"`（或可视标签）；删除按钮 `aria-label="删除待办"`；列表用 `<ul>/<li>`；底部统计 `aria-live="polite"`，统计容器始终保留在 DOM 中，列表为空时清空内容并隐藏，不销毁。
- 对比度：正文 ≥ 4.5:1；`muted-foreground` 在白底约 4.8:1，满足 WCAG AA。
- 键盘：Tab 顺序为输入框、添加按钮、每项勾选框、删除按钮；空格切换勾选，回车添加。
